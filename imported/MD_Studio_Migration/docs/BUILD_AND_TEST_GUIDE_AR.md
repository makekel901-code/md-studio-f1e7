# دليل البناء والاختبار السحابي — MD Studio

## المتطلبات
- حساب GitHub ورمز وصول شخصي محفوظ داخل MD Studio بشكل مشفر.
- الخيار الموصى به: Fine-grained token مع All repositories والصلاحيات Repository creation: write (أو Administration: write)، Contents: write، Workflows: write، Actions: write، Metadata: Read.
- البديل: Classic Personal Access Token بنطاقي `repo` و`workflow`. لا تمنح MD Studio صلاحية `delete_repo`؛ فهي غير مطلوبة.
- عند إنشاء مستودع تلقائيًا، يجب أن يسمح الحساب بإنشاء مستودعات جديدة.
- مشروع Android يحتوي settings.gradle(.kts)، وملف بناء للوحدة app، وAndroidManifest.xml.

## البناء من MD Studio
1. أنشئ الرمز بالصلاحيات المذكورة أعلاه، ثم افتح الإعدادات في MD Studio وأضف حساب GitHub واختبر الاتصال. لا تلصق الرمز في محادثة أو داخل ملفات المشروع.
2. أنشئ مشروع Android أو استورد مشروعًا موجودًا إلى مساحة العمل.
3. افتح مركز البناء وحدد Debug أو Release.
4. اضغط «إنشاء مستودع خاص تلقائيًا ثم رفع المشروع وبناء APK».
5. يستمد MD Studio اسم المستودع من `rootProject.name` في ملفات Gradle، وينشئ مستودعًا خاصًا جديدًا مع README ابتدائي. إذا كان الاسم مستخدمًا، يجرب اسمًا فريدًا بلاحقة رقمية.
6. ينشئ فرع بناء مستقلًا باسم mdstudio/build-* ويرفع ملفات المشروع دون ملفات الأسرار أو ملفات البناء المؤقتة.
7. يضيف أو يحدّث Workflow باسم mdstudio-build.yml على الفرع الافتراضي عند الحاجة، ثم يشغّله على فرع المشروع.
8. يتابع حالة GitHub Actions، ثم ينزّل APK الناتج إلى مساحة MD Studio الداخلية.
9. استخدم «حفظ APK على الهاتف» لتصديره إلى مجلد تختاره، أو افتح مثبت Android من قسم الاختبارات.

## التوقيع
- Debug ينتج APK موقّعًا بمفتاح debug الخاص بالبناء.
- Release يستخدم أسرار MDSTUDIO_KEYSTORE_BASE64 وMDSTUDIO_KEYSTORE_PASSWORD وMDSTUDIO_KEY_ALIAS وMDSTUDIO_KEY_PASSWORD إذا كانت معرفة في إعدادات المستودع.
- إذا لم تُضف أسرار التوقيع، ينتج Release APK غير موقّع. لا تستخدمه كتحديث لتطبيق منشور بتوقيع مختلف.

## الاختبارات
يشغّل Workflow مهمة testDebugUnitTest قبل إنشاء APK عند تفعيل خيار الاختبارات. يتم رفع تقارير الاختبارات كـ Artifact منفصل عند توفرها. كما يتحقق Workflow من وجود ملفات مشروع Android ومن سلامة APK الناتج قبل رفعه.

## ملاحظات مهمة
- لا يحتاج الهاتف إلى JDK أو Gradle أو Android SDK. كل البناء والاختبارات يجريان على GitHub Actions.
- إنشاء المستودع تلقائيًا ينشئ مستودعًا خاصًا جديدًا؛ لا يحذف التطبيق مستودعات ولا يغيّر مستودعًا موجودًا بهذه العملية.
- ملفات المشروع تذهب إلى فرع مستقل؛ لا تُستبدل ملفات المصدر في الفرع الافتراضي. قد يُضاف أو يُحدّث ملف Workflow على الفرع الافتراضي حتى تسمح GitHub بتشغيل workflow_dispatch.
- لا ترفع مفاتيح API أو keystore أو ملفات .env ضمن المشروع.
- حجم المشروع المسموح رفعه من MD Studio محدود حاليًا إلى 50 MB و600 ملف.
