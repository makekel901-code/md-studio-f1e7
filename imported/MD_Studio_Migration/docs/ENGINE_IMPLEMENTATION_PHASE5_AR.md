# MD Studio — دفعة المحركات الخامسة

## ما أُضيف في هذه الدفعة

### 1) إنشاء مشروع Android حقيقي
- `AndroidProjectScaffolder` ينشئ مشروع Kotlin + Jetpack Compose.
- الملفات الناتجة: `settings.gradle.kts` و`build.gradle.kts` و`gradle.properties` وملف وحدة `app` وManifest و`MainActivity.kt` وREADME.
- واجهة المشروعات تسمح بإدخال اسم التطبيق واسم الحزمة، ثم تنشئ المشروع وتجعله المشروع النشط في مساحة العمل.
- لا تدّعي هذه الوظيفة أنها تنشئ تطبيقًا كامل الميزات من وصف طبيعي؛ إنها تنشئ نقطة بداية قابلة للتطوير والبناء.

### 2) مكتبة Maven Central
- `MavenCentralCatalogProvider` يتصل بواجهة البحث العامة في Maven Central.
- شاشة المكتبة تعرض النتائج وإحداثيات Maven.
- إضافة الاعتماد تتطلب ضغط المستخدم على «إضافة».
- قبل تعديل `app/build.gradle` أو `app/build.gradle.kts` تُحفظ نسخة احتياطية باسم `.mdstudio-backup`.

### 3) موفر GitHub Actions المتكامل
- `GitHubActionsBuildProvider` يرفع لقطة المشروع إلى فرع مستقل.
- يشغّل `workflow_dispatch` على الفرع.
- يتابع تشغيل Workflow حتى اكتماله أو انتهاء المهلة.
- يقرأ Artifacts وينزّل APK إلى مساحة التطبيق.
- لا يكتب ملفات المشروع المصدرية إلى الفرع الافتراضي.
- أضيف `headBranch` إلى بيانات Workflow Run لتمييز تشغيل الفرع المطلوب.

### 4) معلومات الجهاز
- `DeviceInfoEngine` يعرض الشركة والطراز وإصدار Android وSDK والمعماريات المدعومة وحد الذاكرة وعدد المعالجات.
- لا يطلب صلاحيات Root أو Shizuku.

### 5) تخطيط الوكيل
- `preparePlanFromModel` يطلب JSON من النموذج.
- يتحقق من أن كل أداة موجودة في سجل الأدوات، وأن الخطة لا تتجاوز 20 خطوة.
- لا ينفذ أي خطوة أثناء التخطيط؛ التنفيذ يظل بعد الموافقة الصريحة.

## الحالة والقيود
- تم توصيل منشئ المشاريع ومكتبة Maven Central في الواجهة.
- تم تجهيز موفر GitHub Actions داخل BuildCoordinator عند توفير حساب ومستودع.
- لا يوجد في هذه الدفعة بناء APK فعلي أو اختبار على هاتف.
- لا تزال محركات PocketBuilder الأصلية غير منقولة حرفيًا؛ المتاح هو إعادة تنفيذ نظيفة لبعض القدرات من الأدلة المستخرجة من APK.
- محركات الصور والفوترة وخدمات Backend/Multiplayer تحتاج مصادر/مزودات مستقلة، ولا تُعد مكتملة.
- Llama يعمل عبر Termux/llama.cpp CLI وليس JNI مدمجًا داخل APK.
