# استكمال هوية AMD Studio ونقل الوظائف الأساسية إلى MD Studio — alpha09

## القرار المعماري

MD Studio هو برنامج التطوير المستقل. AMD Studio هي هوية الاستوديو المطوّر والمالك التي تظهر في معلومات المنتج والتطبيقات المنشأة. AI Studio يظل اسم أداة عمل فقط، ولا يُستخدم كاسم مطوّر أو كهوية شهادة توقيع.

الهدف أن يستطيع MD Studio مواصلة دورة تطوير Android بصورة مستقلة قدر الإمكان، بحيث يكون بديل تشغيل احتياطيًا قويًا عند تعطل أداة AMD Studio الأصلية. لا يعني ذلك أن كل وظيفة أصلية أو كل محرك خارجي أصبح منقولًا أو مكتملًا؛ الحالة أدناه تفصل بين التنفيذ الفعلي والموصلات والوظائف غير المنقولة.

## وظائف AMD Studio الأساسية التي جرى اعتمادها كمرجع

| الخدمات | Backend وMultiplayer وRuntime AI/Search | موصلات عامة قابلة للتهيئة؛ ليست خوادم إنتاج مدمجة |

## ما أضيف في alpha08

1. هوية منتج موحدة داخل الإعدادات: MD Studio، والاستوديو المطوّر AMD Studio، مع توضيح صريح أن AI Studio ليس هوية المطوّر.
2. أيقونة Android تكيفية خاصة بـ MD Studio، مع خلفية كحلية وعلامة هندسية مختصرة.
3. اختيار مظهر فعلي: حسب النظام / فاتح / داكن، مع حفظ الاختيار وتطبيق لوحة ألوان فاتحة أو داكنة على Material 3.
4. إعداد محفوظ لإظهار أو إخفاء تفاصيل متطلبات المحركات.
5. سجل مشروعات محلي دائم يحفظ المسارات والأسماء والحالات وآخر تحديث، ويتيح فتح مشروع محفوظ.
6. تحديث حالة المشروع إلى BUILDING أثناء البناء السحابي ثم COMPLETED أو ERROR حسب النتيجة الفعلية.
7. مركز داخل الإعدادات يعرض سجل المحركات وحالتها الحالية ومتطلباتها، ويميز التنفيذ الفعلي عن الموصل الجاهز وعن المحرك الذي يحتاج مزودًا أو لم يمكن نقله من APK.
8. توضيح نطاق البرنامج: تطوير Android، واجهة عربية RTL، ومسار إنتاج APK المعتمد حاليًا GitHub Actions.
9. توثيق نقل الوظائف الأساسية والفجوات المتبقية بدل وصف جميع وظائف AMD Studio بأنها منقولة.
10. رفع رقم الإصدار إلى `versionCode 8` و`versionName 1.0.0-alpha08`.

## حدود مهمة

- لا يمكن استعادة الشيفرة الأصلية أو الخوارزميات الداخلية لتطبيق AMD Studio/PocketBuilder من APK وحده؛ الوظائف المعروفة أعيد تنفيذها أو توثيقها بصورة مستقلة.
- لا توجد في هذه الدفعة واجهة اختيار لغة متعددة؛ الواجهة عربية RTL حاليًا، ولم نضف خيار لغة شكليًا لا يغير كل النصوص.
- قائمة مزودي الذكاء الاصطناعي ليست مفتوحة بالكامل بعد: Gemini مدعوم بمفاتيح متعددة، وLlama له جسر Termux، وأي مزود آخر يحتاج Adapter فعليًا واختبار اتصال.
- إعدادات النسخ الاحتياطي التلقائي، وحسابات المستخدمين، والفوترة، ومتجر الإضافات، وإدارة فرق العمل ليست مكتملة ولا تُعرض هنا كقدرات منجزة.
- اسم AMD Studio في بيانات المنتج لا ينشئ شهادة توقيع APK؛ التوقيع يعتمد على keystore يملكه المستخدم.

## التحقق

تمت إضافة تغييرات الواجهة والهوية والموارد إلى المصدر. يلزم تشغيل Gradle build على Android SDK/Gradle متوافقين ثم تثبيت التطبيق على جهاز حقيقي للتحقق من الأيقونة والمظهر الداكن والإعدادات. لا تعتبر هذه الوثيقة إثباتًا لبناء APK أو لاختبار جهاز.

## تحديث alpha09 — دورة حياة المشروع والنسخ الاحتياطي

1. توحيد حالات المشروع المسجلة محليًا: CREATED وPLANNING وDEVELOPMENT وBUILDING وTESTING وCOMPLETED وERROR وIMPORTED وARCHIVED.
2. إضافة سجل أحداث محلي دائم لكل مشروع، يحتفظ بآخر 300 حدث إجمالًا، مع وقت الحدث والحالة والتفاصيل. يمكن فتح سجل المشروع من بطاقة المشروع.
3. توثيق بداية البناء السحابي ونتيجته الفعلية داخل سجل المشروع؛ لا تُسجل حالة نجاح إلا عند وصول إيصال بناء ناجح من موفر البناء.
4. إضافة تصدير نسخة ZIP من بطاقة المشروع باستخدام منتقي ملفات Android. يستخدم التصدير مرشح الأمان الموجود في ProjectArchiveManager لاستبعاد مفاتيح التوقيع والأسرار وملفات البيئة وملفات APK/AAB وملفات البناء.
5. تحديث سجل المحركات لتمييز طبقة الوكيل المتاحة برمجيًا عن المدير الهندسي المتكامل الذي لم يُربط بعد بواجهة تنفيذ موحدة.
6. رفع الإصدار إلى `versionCode 9` و`versionName 1.0.0-alpha09`.

## ما لا يزال خارج الاكتمال

- المدير الهندسي متعدد الوكلاء غير متصل بعد بواجهة تنفيذ شاملة في التطبيق؛ طبقة تخطيط الأدوات موجودة لكنها ليست بديلًا عن مدير مستقل كامل.
- Gemini هو المزود السحابي الفعلي المتاح في الواجهة الحالية. إضافة OpenAI-compatible أو Anthropic أو غيرها تتطلب موصلًا واختبارًا وإعدادات آمنة منفصلة.
- خدمات Backend وMultiplayer وRuntime AI/Search تظل موصلات عامة تحتاج خوادم ومفاتيح ومخططات API يملكها المستخدم.
- لا توجد خدمة مزامنة سحابية مستقلة أو حسابات مستخدمين أو تعاون فرق.
- سجل الأحداث محلي على الجهاز ولا يتزامن تلقائيًا بين الأجهزة.
